## 📖 1. Company Introduction

**Wiz** ek game-changing cloud security company hai jise Israeli military ke elite cyber intelligence officers ne start kiya tha. Jab traditional security tools cloud infrastructure ko scan karne ke liye har jagah 'agents' (chote software programs) install karne par majboor kar rahe the, Wiz ne ek completely **Agentless** approach market me laya.

Wiz aapke multi-cloud environments (AWS, Azure, GCP, OCI) se APIs ke zariye connect hota hai aur poore infrastructure ka ek **"Security Graph"** taiyar karta hai. Yeh sirf flaws nahi dhoodhta, balki yeh batata hai ki kaunsa flaw sach me ek hacker ke liye raasta (Attack Path) khol raha hai.

> **💥 History's Biggest Cybersecurity Deal (March 2026 Update):** Wiz ne 2025 me $1 Billion Annual Recurring Revenue (ARR) touch kiya. Google ne iski massive success ko dekhte hue **$32 Billion (all-cash)** me Wiz ka acquisition complete kar liya hai, jo tech history ka sabse bada cybersecurity acquisition hai. Ab Wiz, Google Cloud ka flagship security arm hai lekin yeh baaki saare clouds (AWS, Azure) ko bhi protect karta rahega.

## ⚡ 3. Core Technology & Platform

Wiz ki sabse badi taqat iski deployment speed (just 15 minutes) aur alert accuracy hai.

### Key Technology Concepts:
* **Fully Agentless Snapshot Scanning:** Wiz ko chalane ke liye kisi server par koi agent install nahi karna padta. Yeh cloud vendor ke storage disk ka ek out-of-band snapshot leta hai aur use scan karta hai. Isse production servers par zero load padta hai.
* **The Wiz Security Graph:** Yeh Wiz ka master brain hai. Agar ek server me vulnerability hai, toh traditional tools ek alag alert denge, agar usme leaked password hai toh dusra alert. Wiz in sabhi dot ko connect karke ek graph banata hai: *"Yeh server Vulnerable hai + Internet se exposed hai + Isme Admin password leaked hai."* Yeh combined threat ek **Toxic Combination** banta hai jise Wiz sabse pehle fix karne ko kehta hai.
* **Agentic-Native Security (2026 Framework):** Google Cloud ke saath integrate hone ke baad, Wiz ne interactive **Red, Blue, aur Green AI Agents** launch kiye hain jo autonomous tarike se threat simulation aur automated "one-click PRs" (code fixes) generate karte hain machine-speed par.

### Major Platform Pillars:
1. **CSPM & CWPP:** Cloud environments ki misconfigurations aur chalte hue systems (VMs, Kubernetes, Containers) me malware/vulnerabilities ko check karna.
2. **DSPM (Data Security Posture Management):** Yeh sirf buckets ko scan nahi karta balki uske andar ke actual data (PII, Credit Card details) ko classify karke protect karta hai.
3. **AI-SPM (AI Security Posture Management):** Yeh industry-first feature hai jo "Shadow AI" (developers jo bina bataye cloud me OpenAI, AWS SageMaker ya open-source LLMs use kar rahe hain) ko detect aur secure karta hai.

## 💼 5. Business Model

Wiz ek enterprise-focused **B2B SaaS (Software-as-a-Service)** subscription model par chalta hai.

* **Tier-Based Subscription:** Customer scale ke mutabik plans choose karte hain:
  * *Wiz Essential:* Base security (CSPM, CWPP, Secrets scanning) ke liye.
  * *Wiz Advanced:* Premium controls (DSPM, Identity/CIEM, AI-SPM) ke liye.
* **Workload-Based Pricing:** Annual billing is baat par hoti hai ki customer kitne virtual machine instances, serverless functions, ya cloud resources ko monitor kar raha hai.
* **Multi-Cloud Freedom:** Google ka asset hone ke bawajood, Wiz ka business model independent rakha gaya hai taaki AWS, Azure aur Oracle Cloud ke customers isse natively unke respective marketplaces se buy kar sakein. Isse Google ko cross-platform security revenue milta hai.
